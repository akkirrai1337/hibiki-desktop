  # hibiki desktop

  [English](README.md)

  **hibiki desktop — приложение для Windows с личным каталогом аниме, локальной библиотекой, плеером и прогрессом просмотра на устройстве. Источники подключаются через внешние репозитории; приложение не хранит и не распространяет контент.**

  Также есть [Android-приложение](https://github.com/akkirrai1337/hibiki) с тем же форматом источников.

### 📚 Основные возможности

* Переключение источников аниме; каталог, поиск, фильтры и сортировка учитывают выбранный источник
* Внешние репозитории источников: установка и обновление расширений прямо в приложении ([hibiki-sources](https://github.com/akkirrai1337/hibiki-sources))
* Подробные страницы тайтлов с описанием, жанрами, оценками, связанными аниме, франшизой и похожими
* Выбор серии и озвучки; выбранные плеер и озвучка запоминаются для каждого тайтла
* Встроенный плеер с поддержкой HLS, DASH и MP4, плюс встроенный iframe для источников, которые отдают только его
* Настройки плеера: качество, движок, озвучка, скорость, автопереход и пропуск опенинга/эндинга
* Горячие клавиши, ускоренная перемотка удержанием и запоминание громкости
* Прогресс просмотра, «Продолжить просмотр» с кадрами из плеера и история просмотров
* Локальный профиль со статистикой, стриками, опытом и достижениями
* Локальная библиотека: смотрю, в планах, просмотрено, брошено, отложено и избранное
* Загрузка серий для офлайн-просмотра
* Светлая и тёмная темы, свой акцентный цвет и градиентные фоны в стиле Discord
* Русский, английский и украинский языки приложения
* Опциональный Discord Rich Presence
* Локальный бэкап и восстановление библиотеки, истории, источников и настроек

### 🛠️ Сборка из исходников

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

`npm run build` собирает NSIS-установщик. Приложение собирается и тестируется только под Windows; кросс-сборки нет — `better-sqlite3` компилируется под ту платформу, на которой идёт сборка.
